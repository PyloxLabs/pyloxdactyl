Pyloxdactyl Extensions Development Guide

Build, package and distribute extensions for the Pyloxdactyl panel.

Overview

Pyloxdactyl supports installable extensions. Each extension is a .zip containing a manifest (pylox-extension.json) and an entry file. The extension manager loads enabled extensions at startup, exposes hooks and auth providers, and mounts routes.

Directory Layout

data/extensions/<id>/
  +-- pylox-extension.json
  +-- index.js
  +-- icon.svg (optional)
  +-- assets/ (optional)

Manifest

pylox-extension.json

{
  "id": "example",
  "name": "Example Extension",
  "version": "1.0.0",
  "author": "Author Name",
  "description": "Short description",
  "main": "index.js",
  "icon": "icon.svg",
  "defaultEnabled": true,
  "settings": [
    { "key": "enabled", "label": "Enable something", "type": "boolean" },
    { "key": "api_key", "label": "API Key", "type": "password" },
    { "key": "endpoint", "label": "Endpoint", "type": "text" },
    { "key": "mode", "label": "Mode", "type": "select", "options": ["a","b"] }
  ]
}
  • id: alphanumeric, dash/underscore/dot allowed
  • main: entry JS file (defaults to index.js)
  • settings: schema for admin UI

Entry Point

module.exports = {
  register(api) {
    // called when extension loads
  }
};
// or export register directly

Extension API

MethodDescription
api.routerExpress Router mounted at /extensions/<id>
api.route(method, path, ...h)Register route on root app (supports get/post/put/delete/all). Also api.route(path,h) defaults GET.
api.static(urlPath, dirRel)Serve static files relative to extension dir under its namespace
api.getSetting(key, def)Get persisted setting
api.setSetting(key, val)Update persisted setting
api.on(hook, fn)Register hook handler returning HTML string
api.addAuthProvider(p)Register OAuth provider
api.addAdminSection(s)Register extra admin tab
api.require(name)Require core lib (db,baseurl,i18n,mailer,archive) or npm module
api.log/api.errorPrefixed logging

Hooks

Available hooks (common):

  • auth.login.buttons – injected into login form area
  • auth.register.buttons – injected into register form area

Handler signature: (req, res) => string

Auth Providers

api.addAuthProvider({
  id: 'myprovider',
  label: 'My Provider',
  icon: '<svg...>',
  url: '/auth/oauth/myprovider',
  order: 10
});

Packaging

  1. Create directory data/extensions/<id>/
  2. Add pylox-extension.json and index.js
  3. Zip the contents (not the parent folder) as <id>-<version>.zip
  4. Upload via Admin ? Extensions

Tips

  • Store OAuth table in your own table via api.db.exec()
  • Use baseurl.resolveBaseUrl(req) for public URLs
  • Clean up on reinstall by not assuming state; schema uses CREATE TABLE IF NOT EXISTS
  • Keep JS small and handle errors
Note: Extensions can run arbitrary code. Only install trusted extensions.
